# Customer Churn Analysis 📊

## 🔍 Project Overview
This is an end-to-end customer churn analysis project using Python (Google Colab) and Power BI.
The objective is to identify churn drivers and provide actionable insights for customer retention.

---

## 🧰 Tools & Technologies
- Python (Pandas, NumPy)
- Google Colab
- Power BI
- Power Query
- DAX

---

## 📂 Project Structure
Customer-Churn-Analysis/
├── colab/ # Data cleaning & exploration
├── powerbi/ # Interactive dashboard
├── data/ # Raw dataset
├── screenshots/ # Dashboard preview


---

## 🧪 Data Preparation (Google Colab)
- Loaded and cleaned telecom customer churn data
- Handled missing values and data types
- Performed exploratory data analysis
- Exported cleaned data for Power BI

---

## 📊 Power BI Dashboard
- KPIs: Total Customers, Churned Customers, Churn Rate
- Churn analysis by:
  - Contract Type
  - Payment Method
  - Tenure
- Interactive slicers for user-driven insights

---

## 🧠 Key Insights
- Month-to-month contracts show the highest churn
- Long-term contracts reduce churn significantly
- Customers using electronic check have higher churn
- Higher monthly charges increase churn risk
